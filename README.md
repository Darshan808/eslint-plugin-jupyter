# eslint-plugin

[![npm](https://img.shields.io/npm/v/@jupyter/eslint-plugin)](https://www.npmjs.com/package/@jupyter/eslint-plugin)
[![CI](https://github.com/jupyterlab/eslint-plugin/actions/workflows/build.yml/badge.svg)](https://github.com/jupyterlab/eslint-plugin/actions/workflows/build.yml)
[![Documentation](https://readthedocs.org/projects/eslint-plugin/badge/?version=latest)](https://eslint-plugin.readthedocs.io/en/latest/)

ESLint plugin for Jupyter core and extensions with early error catching and best practices enforcement.

## Installation

```bash
npm install --save-dev @jupyter/eslint-plugin
```

## Usage

Add `@jupyter/eslint-plugin` to the plugins section of your ESLint configuration. For detailed usage instructions and available rules, see the [documentation](https://eslint-plugin.readthedocs.io/en/latest/).
